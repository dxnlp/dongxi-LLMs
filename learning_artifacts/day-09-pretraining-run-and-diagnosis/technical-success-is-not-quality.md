## Four questions that must not collapse into one

1. Did the supervised process finish safely and retain an accepted result?
2. Did it restore the same numerical trajectory without refunding spent work?
3. Did teacher-forced prediction improve on the fixed declared targets?
4. Did free generation deliver a correct, coherent and satisfactorily completed answer?
