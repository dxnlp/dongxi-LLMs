How to read the animation

Prefill retains three positions. Selecting “blue” leaves that cache unchanged. When “blue” is fed back, its K/V are appended before its fresh query reads the four available positions. The remaining model then predicts the next token.

One layer is shown. Token pieces, continuations, and vector glyphs are illustrative. Only the final prompt query is drawn. Flow paths show dependencies, not measured attention weights. The final fade resets the illustration.
