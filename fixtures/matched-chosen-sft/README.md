# Matched chosen response control fixture

The sidecar freezes two tiny CPU seeds, a random local Qwen3 architecture and
explicit authored scenario groups for the existing Chapter11 location fixtures.
Those original train/validation/evaluation bytes are not modified. The frozen
literal WordLevel inventory includes all predeclared fixture vocabulary; no
publication answer is trained on or used for recipe selection.

The [protocol](../../experiments/specs/2026-10-05-matched-chosen-sft-control.md)
defines same chosen exposure versus unequal rejected/reference supervision and
compute. The [actual report](../../experiments/reports/2026-10-05-matched-chosen-sft-control.md)
retains all six negative heldout results and the saved/reloaded local checkpoint
identities. This is original CPU source evidence, not a completed model-scale
assistant comparison or a new generic recovery system.
