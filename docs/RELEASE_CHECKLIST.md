# Course Release Review

This is the concrete Day 28 decision guide. Prepared material and passing checks
support a review; they do not authorize an external publication or invent model
results. Use Chapter 15's release notebook to inspect the evidence record.

## Reader and implementation checks

- All 15 chapters form the declared prerequisite sequence, with consistent
  notation and worked solutions.
- Every one of the 28 days has a usable notebook route, a meaningful intervention
  and an interpretation exercise; future material contains no empty placeholders.
- The CPU references execute from fresh kernels with the recorded dependencies.
- Mathematical invariants, mask/reduction boundaries and verifier edge cases pass
  their independent checks. Source hashes and failures are preserved.
- Generated figures use their current tensors or clearly identified saved data.
  Source notebooks retain learner cells, and fixed previews are labeled references.
- GitHub math source checks and local navigation checks pass.

## Evidence and model checks

- Actual measured runs and proposed Spark protocols are plainly distinguished.
- Result tables include denominators, runtime boundaries, sampling policy,
  uncertainty and relevant negative observations.
- Model cards identify parent checkpoints, data, objectives, templates,
  adaptations, evaluation contracts and known limitations.
- The capstone retains every planned comparison row, including failed generation,
  parsing errors, unresolved criteria and unexecuted branches.
- Dataset and source licenses are recorded. Original course code and prose do
  not imply rights to redistribute third-party training data or model weights.
- A repository release license still needs the owner's choice. This build does
  not silently choose a license for existing intellectual property.

## Operational checks

- Publish only source, compact evidence and permitted static assets. Exclude
  credentials, virtual environments, model weights and raw cache directories.
- A reproduction command points to an actual implemented runner, identifies
  its environment and explains its bounds.
- Heavy training/inference services are deliberately managed; a machine switch
  or material verifier does not start a campaign.
- Public Git, articles, site hosting and weight releases have an explicit
  publication decision and a recoverable revision.

Record the final decision as accepted, accepted with named limitations, or
deferred with specific missing evidence. A deferred model-quality claim can
coexist with a useful executable teaching release.
