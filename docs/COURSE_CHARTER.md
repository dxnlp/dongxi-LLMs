# Course Charter

## Purpose

Build a rigorous, experiment-driven understanding of modern language-model
architecture, training, post-training, evaluation, and failure analysis.

## Learner

The primary learner is a capable Python programmer with foundational deep-learning
knowledge who wants to move from using LLM APIs to designing and defending model
development decisions.

## Learning contract

For each important mechanism, the learner should be able to:

1. explain the idea in plain language;
2. derive the relevant mathematics;
3. implement a small transparent version;
4. test it with a controlled experiment;
5. separate observations from interpretations;
6. identify trade-offs, failure risks, and the next experiment.

## Evidence standard

An empirical claim is supported only when its experiment identity, configuration,
environment, measurements, and representative outputs are preserved. Loss and
reward alone do not establish general capability improvement.

## Scope

The 28-day `v0.1` target is a coherent public beta. Mathematical clarity,
executable code, controlled experiments, and honest evaluation take priority over
breadth.
