# Image Upload Order

01. `assets/prefill-decode.gif` — Prefill predicts “blue”; feeding it back creates its K/V before its query reads all four positions and predicts “.”. One layer is shown; “Rest of model” includes the remaining layers and vocabulary projection. Token pieces and vector glyphs are illustrative; only the final prompt query is shown.
02. `assets/math-attention.png` — Single-head attention: compare the current query with keys through position t, scale by the square root of d, apply softmax, then combine the corresponding values.
03. `assets/append-edit.gif` — Appending E preserves cached A–D. Replacing B with X preserves A but requires recomputing the dependent suffix. Colored vector glyphs show cache identity and validity, not measured activations; recomputation need not change every numerical value.
04. `assets/decode-step.gif` — New h → Q/K/V projections → append new K/V → Q reads past and current keys → softmax weights → weighted V sum. Earlier K/V stay fixed. The weight bars use a calculated toy example, not measured model activations; positional operations and the rest of the model are omitted.
05. `assets/math-memory.png` — Separate K/V payload in bytes: two tensors × batch size × layers × retained positions × KV heads × head width × bytes per element.
06. `assets/memory-growth.gif` — More cached positions: 4,096 → 8,192 gives 192 → 384 MiB. A separate configuration comparison at 4,096 positions: 8 → 4 KV heads gives 192 → 96 MiB. Each column groups 1,024 positions; each row represents one KV head with separate K/V. Other factors remain fixed. Calculated tensor payload only; changing the head count compares architectures, not runtime head removal.
07. `assets/global-sharing.gif` — Encoder output supplies one global bank, created at layer 21 and reused across decoder layers. Each layer retains its own Q and local KV. The lower detail magnifies one selected vector used for both Q matching and weighted accumulation; it is not another allocated bank. Intervening layers and sparse-indexer mechanics are omitted.
