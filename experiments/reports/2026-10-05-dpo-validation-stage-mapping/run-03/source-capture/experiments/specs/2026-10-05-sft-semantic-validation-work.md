# SFT semantic validation consumes persistent work allowance

This premeasurement protocol extends only the actual SFT runner and a new CPU
test and evidence family. It preserves the earlier 838-test source revision and
all SFT work and recovery references as historical. No shared module, earlier
test, canonical document or Git mutation is in this owner scope.

## Versioned units and admission

Use dongxi-sft-logical-work-v2: retain all twelve earlier training, selection,
evaluation and generation dimensions and add recovery_validation_operations,
recovery_history_rows, recovery_tensor_elements and recovery_rng_states.
Require the exact sixteen-key cap vector. Reject
old budgeted v1 contracts and journals; do not infer new allowances or migrate a
snapshot. The original unbudgeted CPU API remains available. The root agent owns
any separately declared compatibility updates to earlier budget test fixtures.

One runner semantic validation consumes one operation, the complete saved
history row count, declared model plus populated Adam plus Torch/CUDA RNG tensor
elements, and one Python, one CPU Torch and each present CUDA RNG state. Tied
state keys count separately because the validator checks them separately.
Populated Adam state counts each scalar step and both moment tensors. Element
units describe the expected layout checked by the semantic validator; they are
not FLOPs or exact internal CPU instructions. Python RNG has bounded fixed
representation but contributes a state, not invented sampler draws. SFT's
deterministic cyclic selector still contributes no new random draws.

Before semantic history, tensor or RNG scans, require completed phase and bounded
exact-integer cursor, plain bounded container lengths, the current v2 science
contract and same physical work-journal prefix. Derive the entire panel from the
already observed model/optimizer/RNG layout and saved completed cursor. Reserve
that complete panel before entry. Reject oversized history/order/state/RNG
containers before traversing them; never estimate a cheaper job by dropping
rows, tensors or RNG states.

Track entered and successfully validated units separately, retaining failed or
open reservations permanently. History rows and tensor/state components complete
individually. A semantic failure must not apply policy, optimizer or live RNG
state. Validate actual saves once before shared serialization; refresh the saved
journal prefix after that validation so its own charge is represented. Restore
uses the actual shared loader callback before any runner state application. If a
caller explicitly validates more than once, charge every invocation.

## Important excluded work

Shared restricted loading, generic tree/finite checks and deserialization occur
before the runner callback on restore; generic serialization checks also occur
after runner save validation. These are EXCLUDED from the new runner-semantic
units and remain a separate pending whole-restore envelope or shared hook.
Hashing, cloning, state application, serialization, general CPU runtime,
activation-checkpoint recomputation, log/export/storage routing and physical
containment are not silently claimed covered. No shared source is edited here.
