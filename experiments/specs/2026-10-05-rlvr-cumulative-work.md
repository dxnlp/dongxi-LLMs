## Frozen accounting contract

The optional CPU API remains unbudgeted unless supplied a WorkLedger. The
production CLI instead requires exact explicit caps and a bounded journal file.
The scientific contract includes the exact dimension map, journal envelope and
permanent conservative reservation convention. Independently retained snapshot
contract/SHA/exact bytes remain required; resume also requires the same anchored
physical journal. Creating a new output directory cannot refill it.

Dimensions distinguish completed updates/collections/source examples, rectangular
generated slots, sampled valid response tokens, actual multinomial draws,
application response targets, uncached generation calls/positions, all policy
and reference calls/positions, old-policy calls/positions, whole evaluation
examples/calls/positions/output tokens and recovery-validation operations/
calls/positions/uniform RNG-validation draws. These intentionally overlapping
counts are not summed as FLOPs. Recovery includes the current source's extra
pending-likelihood forward and uniform sampling checks of historical RNG usage.

A collection reserves group times response cap and the complete uncached
growing-prefix sum, plus old-policy rescoring. An application reserves its
existing pool-validation forward/RNG checks, reference/current score branches,
response targets and optimizer update. A payload check reserves all retained
history RNG checks plus the pending likelihood branch before performing any
of those checks. Evaluation freezes all encoded prompts and reserves the whole
greedy panel before its first forward; encoding errors are not model work.

Every successful logical call is recorded separately from an entered failing
call. Unknown internal failed-forward/backward/optimizer work stays unknown.
Reserved capacity never refunds early stops or failures. Mid-generation
continuation remains outside the durable replay guarantee. WorkLedger is
trusted-local cooperative accounting, not GPU time, recomputation dispatch,
physical containment, aggregate storage quota or adversarial authentication.

For CPU controls, use all dimensions capped at100,000, a1MiB work journal and
the existing16MiB snapshot envelope. Refusal controls lower exactly one declared
dimension before collection; no test score selects a cap or recipe afterward.
