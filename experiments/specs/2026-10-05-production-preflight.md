# Production preflight interface — CPU failure controls

Declared before the first measurement. This experiment creates no services,
cgroups, quotas, containers, GPU contexts, models, dependencies or Git changes.
Its provider observations are authored fixtures, not platform clearance.

## Hypothesis and limits

A nonexecuting, fail-closed interface can distinguish a complete, current,
privately owned backend observation from missing, stale, raced or malformed
evidence. A leader exit0 cannot satisfy a separate owned-boundary drain check.
All accepted receipts must retain `scope=authored-local-fixture`,
`production_ready=false` and `launch_authorized=false`. Actual platform mode has
no adapter and must refuse even a structurally valid fixture.

Use two bounded JSON observations of the same stage/preparation/nonce, with
increasing observation sequence and a stable private-boundary identity.
Require independently named containment, hard aggregate byte/entry quota,
bounded-observer and external-watchdog adapters, GPU-owner inspection, complete
membership and sampled host reserve at least25GiB. A claimed timeout field is
not real timeout enforcement; these source tests validate its contract only.

Only sanitized counters and opaque owned-instance identities enter the receipt.
No raw process arguments, environments or discovered-PID signal targets exist
in this API. Reject duplicate keys, unknown fields, booleans masquerading as
integer counters, nonfinite timing, overlarge payloads, incomplete scans,
conflicts, low host reserve, unarmed watchdog, missing quota and unstable scope.
Refuse cleanup success with retained workers, unreadable membership, wrong scope,
failed cleanup or a nonzero leader exit. Never signal any process.

## Measurement

Run the new `test_production_preflight.py` under the already isolated CPU course
environment with CUDA hidden/offline libraries and one numerical thread. Retain
actual command, exit, elapsed time, stdout/stderr and source/spec/test hashes
before and after. Bound the external test command to60seconds. The positive
control and every negative boundary are injected; no successful test establishes
production containment, quota, observer deadlines, real GPU idle state or
global resource safety. Historical campaign outcomes and Day9 remain unchanged.
