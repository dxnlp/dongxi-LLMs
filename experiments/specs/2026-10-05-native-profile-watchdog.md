# Native profile supervision and portable CPU replay

This source verification contract precedes new implementation checks. It closes
two concrete omissions in the original improvement plan: an external controller
for the intended native assistant profile and a portable resource boundary for
the existing tiny story replay controls. It does not authorize acquisition,
pretrained inference, a Spark profile or any later campaign stage.

## Native profile source scope

Build one adapter for `assistant-profile-base06`, not an arbitrary shell or
general campaign scheduler. It must construct the existing native
`scripts/run_chapter09_spark_sft.py` invocation: Qwen3-0.6B-Base at
`da87bfb608c14b7cf20ba1ce41287e8de496c0cd`, full mode, 20 updates, microbatch 1,
accumulation 4, maximum length 256, seed 1212, learning rate 2e-5,
checkpoint interval 20, 900-second runtime ceiling and 25 GiB host reserve.
There is no acquisition flag, arbitrary extra argv, resume, pilot or follow-on
row. Required interpreter, actual local inputs, template, lock, cap files,
snapshot byte envelope, output and journal locations must be explicit.

Unknown encoded targets and allowances remain unresolved. Do not fill them using
tiny CPU fixture values or turn a caller's declaration into authenticated
approval. A prepared source command is not launch permission. The runnable entry
point must default to nonexecuting inspection/preparation; real execution
requires separately scoped operator authority and explicit invocation.

The controller launches only its constructed native command under an owned new
session, not a shell. Its independent deadline must keep advancing while the
native child blocks. Resource probes must not block that deadline controller.
Declare bounded TERM grace, KILL/reaping and cleanup on observer/journal failure
or interruption. Signal only the invocation's owned child/session and observed
owned descendants; never signal a conflicting process discovered by inspection.
Missing, conflicting or incomplete resource clearance refuses launch.

Retain labelled sampled Linux `MemAvailable`, conservative sanitized conflict
observations, actual child identity/argv, exit or signal, stop reason and failed
or partial logs. Acquisition remains disabled. Sampling is not a continuous
memory guarantee, an authenticated approval service, hard aggregate quota,
cgroup, hostile-descendant containment or proof of an idle GPU. Do not imply
those supporting production plans are finished.
